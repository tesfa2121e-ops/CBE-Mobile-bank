# CBE

A mobile banking app UI built for **training and learning only**.
All money, names and account numbers are fake. It is not connected to any bank
and is not affiliated with Commercial Bank of Ethiopia.

## Features
- Home screen with hide/show balance
- CBE Transfer: account number, receiver name, amount, remark
- Recent Transfers and Beneficiaries lists
- Confirm screen, 4-digit PIN pad, success screen with QR code
- Mini Statement

## Run it
Open `index.html` in a browser. No build step needed.

## Publish with GitHub Pages
Repo Settings > Pages > Deploy from branch > `main` / `(root)`.

## Install on your Android phone (personal use, not the Play Store)
1. Upload all 6 files in this folder to your GitHub repo, and turn on GitHub Pages (see above).
2. On your phone, open the Pages link in **Chrome**.
3. Tap Chrome's **⋮ menu > Add to Home screen > Install**.
4. The app now opens full-screen from its own home screen icon, with no browser bar, and works offline after the first open.
